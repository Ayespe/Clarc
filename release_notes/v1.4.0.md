### Added

- Model picker now offers the new **Fable 5** model (the `fable` alias), and the `best` alias resolves to Fable 5 where available. Raw model IDs like `claude-fable-5` render as "Fable 5".
- Chat effort pickers gain a session-only **Ultracode** option, available from the toolbar menu, the `/effort` sheet, and the `/effort` command.

### Changed

- Effort level descriptions now match the latest Claude Code: `high` is the default on current models, and `xhigh` offers deeper reasoning. The outdated `max` effort note ("Opus 4.6 only") has been corrected — `max` is session-only on all effort-capable models.
